# Blender-built vehicles

All models in this folder are original work generated by this project's own Blender scripts
(`tools/blender/carbody.py`, `tools/blender/cars.py`, `tools/blender/plane.py`) and are released
under CC0 together with the rest of the game's procedural content. No third-party meshes, textures,
logos or trademarks are used; designs are fictional ("Bison 69", "Shera S9", "Gajraj G6",
"Rajhans R7") and carry made-up badges.

Rebuild (needs `pip install bpy`; output goes to `tools/blender/out/cars`, or `$DD_OUT`):

    python3 tools/blender/cars.py -- bison shera gajraj
    python3 tools/blender/plane.py

Each car exports `<key>.glb` (player detail), `<key>_lod1.glb` / `<key>_lod2.glb` (traffic),
the matching `_wheel` files and `cars.json` (wheel placement). Vertex data: COLOR_0 = albedo x baked
ambient occlusion (linear), TEXCOORD_0 = (paint flag, material code) read by `src/carmodels.js`.
