## Daman Duo

**Downloads**
- **Android phone:** `DamanDuo-Android.apk` — download on your phone, open it, allow "install unknown apps" if asked.
- **Windows PC:** `DamanDuo-Windows-Setup.exe` (installer) or `DamanDuo-Windows-Portable.exe` (no install).
- **Linux:** `DamanDuo-Linux.AppImage` (chmod +x, then run).
- **macOS:** `DamanDuo-macOS.dmg` (unsigned: right-click → Open the first time).
- **Browser:** `DamanDuo-Web.html` — open in Chrome/Edge.

Desktop builds start in Ultra graphics; the Android build starts in the Mobile preset with touch controls. Change anything in Settings.
