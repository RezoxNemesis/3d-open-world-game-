# Daman Duo

An open-world 3D action game set in Daman, India — built entirely in code. Play as a duo across a huge map of Daman: Moti Daman and Nani Daman forts, Devka and Jampore beaches, the Daman Ganga river, the airport, farms, jungle and the mountains beyond.

Downloads for Android and Windows/Linux/macOS are on the [Releases page](../../releases).

_Full feature list and controls are being written as the game is built._
